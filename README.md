# EHA 事件时间与效率评价研究

本仓库用于存放海洋数据挖掘课程大作业相关文档。选题围绕**事件时间与到达时间的区别**这一具体知识点，研究压力—流量错误配对及物理相位误校正对 EHA 泵端效率评价的影响。

研究过程中，通过与 AI 进行多轮讨论，逐步完成选题聚焦、物理模型构建、数学公式推导、实验场景设计、结果分析及研究结论修订，并重点围绕时间配对误差、物理相位与时钟偏移的区别、互相关误校正、方案比较公平性及误差边界进行了深入探讨。

GitHub 仓库公开存放课程研究报告、学生—AI 研究讨论整理文档及相关研究材料，供教师查阅研究思路、讨论过程与结果分析。
